# Grill-me（グリルミー）スキル（MAKASERU）

AIに「**グリルして**」と頼むだけで、あなたの「作りたい」「困っている」を、**1問ずつ質問して**、頭の中をきれいに整理してくれる"考えるための相棒"です。
横に**優しい先輩エンジニア**が座ってくれるイメージで作っています。

- 何を作ればいいか、モヤっとしている時に、AIが1問ずつ聞いてハッキリさせてくれる
- 毎回「おすすめ＋理由」付きで聞いてくれるので、答えるだけで決まっていく
- **説明のプロ**：専門の言葉や「ターミナルで実行して」のような指示を、日常の言葉に言い換えてくれる
- **安全の目**：パスワードを貼りそう、消すと戻せない、お客様に送る、といった危ない所は、先に止めて理由を教えてくれる
- 「作ってみたい」と言えば、作るところにも1手ずつ付き添ってくれる

> まずは「**やりたいことを言葉にする**」ところから。いきなり作り始めないのが、このスキルの良さです。

## いちばん簡単な入れ方（Claude に貼るだけ）

Claude の新しいチャットに、この文をそのまま貼ってください。

```
次の GitHub にあるスキルを、
ネットから自分の PC に持ってきて、
スキルとして使えるようにしてほしいです。

https://github.com/kawataro0831-hash/makaseru-grill-me
```

Claude のアプリ（チャット）で、Claude が ZIP ファイルを渡してきたときは、設定の「Customize」→「Skills」→「＋」→「Upload a skill」で、その ZIP を選んでください（ZIP は開かずにそのまま選ぶ）。

## 手で入れる方法（Windows・3ステップ）

**① このページの緑の「Code」ボタン → 「Download ZIP」を押してダウンロード**

（Gitが使える方は `git clone https://github.com/kawataro0831-hash/makaseru-grill-me.git` でもOK）

**② ZIPを開いて、中のフォルダを「スキル置き場」にコピー**

スキル置き場の開き方：キーボードの `Windowsキー + R` を押して、出てきた窓にこれを貼り付けてOK：

```
%USERPROFILE%\.claude\skills
```

（フォルダが無いと言われたら、エクスプローラで `C:\Users\自分の名前` を開き、`.claude` フォルダ →その中に `skills` フォルダを作ってください）

コピーしたら、フォルダ名を `grill-me` に変えておくとわかりやすいです。

**③ Claudeアプリを一度終了して、開き直す**

これで準備完了。入力欄で `/` を打つと「grill-me」が出てきます。

## 使い方

チャットにこう書くだけです：

```
グリルして。おちょこを紹介するブログ記事を、毎回ラクに書けるようにしたい
```

```
グリルミー。日報を書くのが面倒だから、なんとかしたい
```

すると、AIが**いきなり作り始めず**、まず「誰に向けて？」「何のために？」「どこで一番詰まる？」…と**1問ずつ**、おすすめ付きで聞いてくれます。答えていくうちに、頭の中のモヤモヤが、そのまま"設計図の材料"になります。

最後に、AIが【決まったこと／まだ決まっていないこと／次の一歩】を3つにまとめてくれます。

## お手本

- `references/example-grillme.md`：グリルミーのやり取り例（おちょこ紹介ブログの相談）
- `references/example-senpai.md`：「ターミナルで実行して」と言われて止まった時や、API キーを貼りそうになった時の付き添い例
- `references/kotoba.md`：よく出る専門の言葉の言い換え集（ターミナル、クローン、API キーなど）

## 「これ、プロンプトと何が違うの？」

いい質問です。**中身はほぼプロンプト（お願いの文章）です**。違うのは「その場限りか／名前を付けて保存して、いつでも呼べるか」だけ。

- **プロンプト** ＝ その場で口頭でお願いする（毎回言い直す）
- **スキル** ＝ そのお願いを「レシピカード」にして棚に貼る（`/grill-me` で何度でも呼べる）

カレーのレシピカードを開いたら、口で言うのと同じ言葉が書いてある——それと同じです。

## 困ったら

| 症状 | 対処 |
|---|---|
| `/` を打っても grill-me が出ない | 置き場所（上の②）を確認 → Claudeを完全に終了して開き直す |
| AIがいきなり作り始めてしまう | もう一度「1問ずつ聞いて」と伝える |
| AIの説明に分からない言葉が出てきた | そのまま「それってどういう意味？」と聞く |
| 質問が多くて疲れる | 「もう十分」「ここまででいい」と言えば、すぐ止まります |

それでも解決しなければ、MAKASERU（川口）まで。
