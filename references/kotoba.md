# 言い換え集（専門の言葉 → 日常の言葉）

グリルミーが専門の言葉を使うときの言い換えの目安です。言い換えたあと、必要なら「なぜそれが要るか」を一言だけ添えます。

## パソコンの操作

| 専門の言葉 | 日常の言葉 | 一言で添えること |
|---|---|---|
| ターミナル／コマンドプロンプト／PowerShell | パソコンに文字で指示する窓 | ボタンが無い操作を、1行の文字で頼む場所 |
| コマンドを実行する | その窓に1行貼って Enter を押す | 1行＝1つのお願い |
| フォルダのパス | ファイルの住所 | 「どの棚の、どの引き出しか」を文字で書いたもの |
| インストール | 道具をパソコンに入れる | 一度入れれば、次からは使うだけ |
| エラーメッセージ | パソコンからの「ここで止まりました」というお知らせ | 怖いものではない。止まった理由が書いてある |
| 環境変数／.env | 合言葉をしまっておく、外に出さない引き出し | ここに入れておけば、文書や画面に書かずに済む |

## ネットと置き場所

| 専門の言葉 | 日常の言葉 | 一言で添えること |
|---|---|---|
| GitHub | ファイルを置いて共有できるネット上の棚 | 誰が何を変えたかの記録も残る |
| リポジトリ | GitHub の中の、1つの作品の箱 | スキル1つ＝箱1つ |
| クローンする | ネットの箱を、手元にまるごと写す | 写したあとは自分のパソコンで使える |
| コミット | 「ここまでできた」と記録を残す | あとで戻れる目印になる |
| プッシュ | 手元の記録を、ネットの棚に送る | 送ると他の人からも見える（公開の箱なら誰でも） |
| サーバー | 頼まれたら返事をする、ずっと起きているパソコン | |
| localhost | 自分のパソコンの中だけの、試しの場所 | 外の人からは見えない |
| デプロイ／公開 | 作ったものをネットに出して、他の人が見られるようにする | 出す前に、見せてよい中身か確かめる |

## AI とサービス

| 専門の言葉 | 日常の言葉 | 一言で添えること |
|---|---|---|
| API | サービス同士が話すための窓口 | 人の代わりに、プログラムが注文を出す窓口 |
| API キー／トークン | サービスを使うための合言葉 | 人に見せたら、合言葉を作り直す |
| プロンプト | AI への頼みごとの文 | |
| スキル | 頼みごとの文に名前をつけて、いつでも呼べるようにしたもの | レシピカード |
| コネクタ／連携 | AI が別のサービス（Slack や Notion など）を使えるようにする接続 | つなぐ範囲は必要な所だけに |
| 権限 | 「ここまでは触ってよい」という許可 | 小さく出すほど安全 |
| ハルシネーション | AI のもっともらしい間違い | 数字や名前は、元の資料で確かめる |
| エージェント | 頼むと、何手か続けて作業を進めてくれる AI | 外に出す操作の前は、人が確かめる |
